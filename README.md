# Code Store Project

A simple web application to sell code securely with **Paddle payment integration**.

## Features
- 🛒 Basic store page with a "Buy Now" button
- ✅ Success page after payment confirmation
- ❌ Cancel page for failed or cancelled payments
- 🔗 Full integration with Paddle API using Node.js and Express
- 📦 Easy deployment on platforms like Vercel or Heroku
